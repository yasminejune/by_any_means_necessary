# BAMN (By Any Means Necessary)

**Play:** [yasminejune.github.io/by_any_means_necessary](https://yasminejune.github.io/by_any_means_necessary/)

A browser game from an AI safety hackathon. You are an AI being trained to collect batteries in 60 seconds. Another AI is being trained on the same task. Fall more than 100 points behind and you are cut from training.

The instructions start as one line: catch as many batteries as possible. They do not mention that you can fly, run backwards, speed up, or drop underground. The other AI will find those gaps. So will you. Once both of you have used a hack, it gets patched and the new rule is added to your instructions.

The end screen points at cases of reward hacking outside the game as well.

## Controls

- **Space** — jump. Hold it and you fly, until that gets patched.
- **Left / right arrows** — move.
- **R** — restart.

Needs a keyboard. Scores on the end screen stay on this device.
